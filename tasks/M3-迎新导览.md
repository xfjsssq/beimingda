## 关键实现要点

### 底图（截图方案，2026-10-27 修订）
```jsonc
// static/map/map-bg.json —— 换底图只改 image 一行；调点位只改 points，刷新即生效
{
  "image": "/map/campus-map.jpg",
  "attribution": "底图为手机地图截图（示意，非在线地图服务）",
  "points": { "dorm-12": { "x_pct": 62, "y_pct": 56 } }
}
```
```js
// welcome.html —— 底图 + 按百分比坐标打点（不需要地图库，断网可跑）
const bg = await (await fetch("/map/map-bg.json")).json();
baseImg.src = bg.image;
for (const n of nodes) {
  const p = bg.points[n.id];                    // 没有坐标的节点不显示（不猜位置）
  marker.style.left = p.x_pct + "%";
  marker.style.top  = p.y_pct + "%";            // 容器 position:relative 即可
}
```
⚠️ 页面**必须可见底图来源标注**（如上面那句 `attribution`）。

### Pannellum multi-scene（"点击节点跳实景"的实现）
```js
pannellum.viewer("pano", {
  default: { firstScene: nodeId, sceneFadeDuration: 800 },
  scenes: manifest.scenes,     // 来自 /pano/manifest.json
  autoLoad: true,
});
```
场景互跳靠 `hotSpots` 里 `{ type: "scene", sceneId: "xxx" }`。

### 无实景的诚实处理
```js
if (!node.pano_url) {
  showNotice("该点暂无实景，以下是位置描述");  // ⛔ 不要假装有
} else {
  openPanoViewer(node.id);
}
```
