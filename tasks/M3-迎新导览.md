## 关键实现要点

### 天地图瓦片（影像底图）
```js
const TILE_KEY = window.__TILE_KEY__;   // 由后端注入，不硬编码
L.tileLayer(
  `https://t{t}.tianditu.gov.cn/img_w/wmts?SERVICE=WMTS&REQUEST=GetTile` +
  `&VERSION=1.0.0&LAYER=img&STYLE=default&TILEMATRIXSET=w&FORMAT=tiles` +
  `&TILEMATRIX={z}&TILEROW={y}&TILECOL={x}&tk=${TILE_KEY}`,
  { subdomains: "01234567", maxZoom: 18, attribution: "地图服务由天地图提供" }
).addTo(map);
```
⚠️ `attribution` 那一句必须有。

### Pannellum multi-scene（"点击节点跳实景"的实现）
```js
pannellum.viewer("pano", {
  default: { firstScene: nodeId, sceneFadeDuration: 800 },
  scenes: manifest.scenes,     // 来自 /pano/manifest.json
  autoLoad: true,
});
```
场景互跳靠 `hotSpots` 里 `{ type: "scene", sceneId: "xxx" }`。

### 无实景的诚实处理
```js
if (!node.pano_url) {
  showNotice("该点暂无实景，以下是位置描述");  // ⛔ 不要假装有
} else {
  openPanoViewer(node.id);
}
```
