## 关键实现要点

### 统一 API 封装（所有页面必须用它，不许各写 fetch）
```js
// static/js/api.js
export async function api(path, opts = {}) {
  const res  = await fetch(path, opts);
  const json = await res.json();
  if (!json.ok) throw Object.assign(new Error(json.error?.message || "请求失败"),
                                    { code: json.error?.code });
  return json.data;
}
```

### ⭐ `/agent` 页的复制按钮
```js
const MCP_CONFIG = {
  mcpServers: {
    beimingda: {
      url: "https://demo.knowingly.dpdns.org/mcp",
      headers: { Authorization: "Bearer <DEMO_TOKEN>" }
    }
  }
};
document.getElementById("copy-btn").onclick = async () => {
  await navigator.clipboard.writeText(JSON.stringify(MCP_CONFIG, null, 2));
  const btn = document.getElementById("copy-btn");
  btn.textContent = "已复制 ✓";
  setTimeout(() => (btn.textContent = "复制配置"), 2000);
};
```
⚠️ 展示的 JSON 里令牌**必须是占位符 `<DEMO_TOKEN>`**，不许填真值。
