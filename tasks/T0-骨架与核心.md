## 关键实现要点

### 统一信封
所有 API 与 MCP 返回都走：
```js
const ok  = (data) => ({ ok: true,  data, error: null });
const err = (code, message) => ({ ok: false, data: null, error: { code, message } });
```
放在 `src/util/envelope.js`，**所有模块共用**，不许各写一份。

### 时间处理
- 存库：**Unix 秒**（INTEGER）
- 出接口：**ISO 8601 带时区**
- 转换封装在 `src/util/time.js`：`toTs(iso)` / `toIso(ts)`

### MCP 端点（关键：短请求，禁 SSE）
```
POST /mcp   —— 单请求单响应，JSON-RPC 风格
GET  /mcp   —— 返回能力描述（可选）
⛔ 不得实现 SSE 长连接保活（CF 隧道 100 秒硬限制）
```
必须支持标准 MCP 方法：`initialize`、`tools/list`、`tools/call`。
