手动标注工具

在学校《校园楼宇编号示意图》上点出标注点 → 填颜色 / 备注 / 类别 → 「复制 JSON」或「下载 JSON」。 数据只在本机（内存 + localStorage，键名 beimingda.annotations）， 不发任何请求、不写服务器，刷新不丢。

100%

滚轮（或滑动条 / ＋－）缩放、按住拖动平移；在底图上点一下就在该处落一个标注点。 已有标注点可拖动改位置，点一下可改颜色 / 备注 / 类别，或删除。

标注点 0

还没有标注点 —— 在左边底图上点一下即可。

导出 JSON

{ "points": [] }

格式：{ "points": [ { x_pct, y_pct, color, note, category } ] }； x_pct / y_pct 是相对底图的百分比（左上角 0,0）。

类别

类别只写进 JSON 供人看，不参与任何计算。
