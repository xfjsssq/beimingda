# pano/ 全景素材

由 `tools/stitch-pano.py`（v2，2026-10-30）从手机实拍的「两段 180°」拼成 360° 等距柱状全景。

## v2 修掉的三类观感问题

| 问题 | 原因 | 现在怎么处理 |
|---|---|---|
| 天空/地面一圈竖向拉丝 | 用镜像行/逐列均值补天补地，顶行本身就含树干树冠，被拉成竖条 | 改成**雾化色带**：取该带中位色 + 左右两端线性过渡，再做强模糊；上下界线另做羽化 |
| 接缝处地平线不齐 | 只搜水平偏移 | 接缝搜索升级为**两轴（dx+dy）**，并**两种拼接顺序都试**取匹配更好的 |
| 接缝两侧明暗割裂 | 亮度对齐只在 B 的左侧 25% 估计 | 改用**真实重叠区**统计（同一片场景）估计增益/偏移，并沿水平平滑过渡；融合带 ≥180px |
| 环视一圈回到起点看到竖线 | 没做环闭合 | 最左/最右各取 3.5% 做**羽化闭环** |
