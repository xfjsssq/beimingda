## 2. `/` 门户首页要素

**区块一 · 顶部标语**：一句话定位 + 副标语

## 3. ⭐ `/agent` 页面（评委最该看的一页）

**这一页是评委理解"能复用"的唯一入口，必须做扎实。**

| 区块 | 内容 |
|---|---|
| 一 | 一句话说明：本项目把平台能力通过 MCP 开放给 WorkBuddy，**用对话即可操控整个平台** |
| 二 | **可一键复制的 MCP 配置 JSON**（`<DEMO_TOKEN>` 占位，旁边说明令牌只读限频） |
| 三 | **四步接入指引**：① 打开 `~/.workbuddy/mcp.json` ② 粘贴配置 ③ 重启 WorkBuddy ④ 连接器管理页点一次「信任」 |
| 四 | **可复制的示例对话**（4-5 条，覆盖四个模块） |
| 五 | **14 个 MCP 工具名一览**，按模块分组 |
| 六 | 一句话合规声明：不收集身份信息、不接学校内部系统、演示令牌只读限频 |

**一键复制的实现**：`navigator.clipboard.writeText(...)`，按钮点击后给"已复制"反馈。

### 示例对话文案（直接照抄）
```
帮我发个代取，12 号楼取快递送到 15 号楼，今晚 8 点前，报酬 3 到 5 块
我今晚 6 点到 9 点有空，12 到 16 号楼都能去，报酬 2 块以上就行
我想找个一起自习的搭子，大二，工科，晚上比较有空，喜欢算法和摄影
帮我看看 15 号楼在哪，有实景吗
周三下午要交实验报告，提前两小时提醒我
```

## 5. 演示模式（`?demo=1`）

URL 带 `?demo=1` 时：
- 所有姓名显示为「同学A / 同学B…」
- 所有学号不出现（本来就不该出现）
- 页面右上角显示一个**"演示模式"徽章**
- 数据来自 `/api/demo/seed`（全部 `demo=1`）

**决赛现场路演与抖音直播一律使用 `?demo=1`。**

---

## 6. 本层禁止事项

- ⛔ 页面出现任何真实姓名 / 学号 / 手机号
- ⛔ **课表上传控件**（`<input type="file">` 用于课表的）—— 刻意不做
- ⛔ 首页统计数字写死
- ⛔ 依赖外部 CDN（第三方库必须本地化到 `static/vendor/`，保证离线可跑）
- ⛔ 在没有实景的点位上假装有实景
